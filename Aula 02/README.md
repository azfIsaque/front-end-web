# 🌍 Aula 02 — Introdução ao HTML

[⬅️ Voltar ao README principal](../README.md)

## 📌 Resumo da atividade

Primeiro contato com o **HTML5**. Nesta aula foram criadas as primeiras páginas, partindo de um texto simples sem nenhuma marcação até uma página com a estrutura completa de um documento HTML. Cada arquivo explora um grupo de elementos: títulos, parágrafos, listas e tabelas.

## 📂 Arquivos da pasta

| Arquivo | O que faz |
|---|---|
| `mensagem-inicial.html` | Texto puro ("Olá mundo!") sem marcação HTML, o ponto de partida da disciplina |
| `minha-primeira-pagina.html` | Primeira página com a estrutura completa: `h1`, `h2` e `p` |
| `anatomia-tags.html` | Anatomia das tags, com parágrafos e destaque em `<strong>` (negrito) e `<em>` (itálico) |
| `elementos-titulo.html` | Os seis níveis de título, de `<h1>` a `<h6>` |
| `listas.html` | Lista não ordenada (`<ul>`) e lista ordenada (`<ol>`) com `<li>` |
| `tabelas.html` | Tabela com `<thead>`, `<tbody>`, `<tr>`, `<th>` e `<td>` |

## 🧠 Habilidades abordadas

- Estrutura básica de um documento: `<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`
- Configuração do `<head>`: `<meta charset="UTF-8">`, `viewport` e `<title>`
- Tags de abertura e fechamento, e hierarquia de títulos
- Parágrafos e ênfase de texto (`strong` e `em`)
- Listas ordenadas e não ordenadas
- Tabelas com cabeçalho e corpo, e uso do atributo `border`
- Indentação e organização do código

## 👀 Como visualizar

Abra qualquer arquivo `.html` da pasta no navegador. Não há dependências nem arquivos externos.
