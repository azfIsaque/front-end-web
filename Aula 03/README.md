# 🏗️ Aula 03 — HTML5: estrutura e conteúdo

[⬅️ Voltar ao README principal](../README.md)

## 📌 Resumo da atividade

Aprofundamento do HTML5 com foco em **conteúdo**: imagens locais e remotas, quebras de linha, linhas horizontais, comentários e legendas com `figure`. Também há um primeiro exemplo que junta as três linguagens (HTML, CSS e JavaScript) em um único arquivo.

## 📂 Arquivos da pasta

| Arquivo | O que faz |
|---|---|
| `exemplo_aula_1.html` | Tabela de dados com `<br>`, `<hr>` colorida, comentários HTML e uma imagem local |
| `exemplo_aulo_2.html` | Imagens em vários formatos (JPG e GIF locais e um GIF da internet), com `alt` e `width` |
| `exemplo_aula_3.html` | Exemplo com **HTML + CSS + JavaScript**: estilo incorporado no `<head>` e `console.log` |
| `logotipo_google.html` | Imagem com legenda usando `<figure>` e `<figcaption>`, com estilo inline (borda, cantos arredondados, `padding`) |
| `img/shadow.jpg` | Imagem usada nos exemplos 1 e 2 |
| `img/pato.gif` | GIF animado usado no exemplo 2 |

## 🧠 Habilidades abordadas

- Inserção de imagens com `<img>`: atributos `src`, `alt` e `width`
- Referência a arquivos por **caminho relativo** (`img/shadow.jpg`) e por **URL externa**
- Formatos de imagem para web: JPG e GIF
- Quebra de linha (`<br>`), linha horizontal (`<hr>`) e **comentários** (`<!-- -->`)
- Agrupamento de imagem e legenda com `<figure>` e `<figcaption>`
- CSS **incorporado** (`<style>`) e CSS **inline** (atributo `style`)
- Primeiro uso de JavaScript com `<script>` e `console.log()`
- Revisão de tabelas (`thead`, `tbody`, `th`, `td`)

## 👀 Como visualizar

Abra os arquivos `.html` no navegador e mantenha a pasta `img/` junto deles. Alguns exemplos usam imagens da internet, então é preciso estar conectado.
