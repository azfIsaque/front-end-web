# 🧱 Aula 04 — HTML semântico e formulários

[⬅️ Voltar ao README principal](../README.md)

## 📌 Resumo da atividade

Introdução ao **HTML semântico**: em vez de usar apenas blocos genéricos, a página passa a ser marcada com elementos que descrevem o papel de cada parte (artigo, cabeçalho, seção e rodapé). A aula também trabalha links, a tag `<div>` e o primeiro estilo aplicado por seletor de elemento e de `id`.

> 💡 A parte de formulários do tema aparece nos exemplos da [Aula 05](../Aula%2005).

## 📂 Arquivos da pasta

| Arquivo | O que faz |
|---|---|
| `exemplo-aula01-link.html` | Imagem e link externo que abre em nova aba (`target="_blank"`), com fundo colorido via CSS |
| `exemplo-aula02-pagina-semantica.html` | Página semântica com `<article>`, `<header>`, `<time>`, `<section>` e `<footer>` |
| `exemplo-aula03-div.html` | Duas divisões `<div>` identificadas por `id`, separadas por `<hr>` e com `<br>` |
| `exemplo-aula04-div_css.html` | O mesmo exemplo da `div`, agora estilizado: fundo, borda, `padding`, `margin` e `border-radius` |

## 🧠 Habilidades abordadas

- **Elementos semânticos:** `article`, `header`, `section`, `footer` e `time` (com `datetime`)
- Diferença entre elementos semânticos e o bloco genérico `<div>`
- Hiperlinks com `<a href>` e `target="_blank"`
- Texto alternativo em imagens (`alt`) para acessibilidade
- Atributo `id` para identificar elementos
- CSS incorporado: seletor de tag (`div`, `hr`) e seletor de `id` (`#principal`, `#secundaria`)
- Propriedades de caixa: `padding`, `margin`, `border`, `border-radius`
- Cores em nome, hexadecimal com transparência e `rgb()`

## 👀 Como visualizar

Abra os arquivos `.html` no navegador. O exemplo de link usa uma imagem da internet, então é preciso estar conectado.
