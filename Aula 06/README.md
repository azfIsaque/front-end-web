# 🎨 Aula 06 — Introdução ao CSS

[⬅️ Voltar ao README principal](../README.md)

## 📌 Resumo da atividade

Primeiro contato com o **CSS3**. A aula mostra duas formas de aplicar estilos, em arquivo **externo** e **incorporado**, e dois tipos de seletor: o de **tipo** (por tag) e o de **classe**.

## 📂 Arquivos da pasta

| Arquivo | O que faz |
|---|---|
| `exemplo-de-aula01-cssexterno.html` | Página "Aprendendo CSS externo", ligada ao `estilo.css` com `<link>` |
| `estilo.css` | Estilos por tag: `body`, `h1`, `h2`, `section`, `p` e `a`, em tons de verde sobre fundo claro |
| `exemplo-de-aula02.html` | "Estudando Classes em CSS": CSS incorporado com `.titulo`, `.caixa01`, `.caixa02`, `.paragrafo1` e `.paragrafo2` |

## 🧠 Habilidades abordadas

- Sintaxe de uma regra CSS: **seletor**, **propriedade** e **valor**
- CSS **externo** (`<link rel="stylesheet">`) e CSS **incorporado** (`<style>`)
- Seletor de **tipo** (`body`, `h1`, `section`, `p`, `a`)
- Seletor de **classe** (`.nome`) e uso do atributo `class`
- Reaproveitamento de estilo: a mesma classe em vários elementos
- Cores (`rgb()` e nomes como `rebeccapurple`), fontes, alinhamento de texto e peso (`font-weight`, `font-style`)
- Espaçamentos e bordas: `padding`, `margin`, `border`, `border-radius`
- Centralização de bloco com `max-width` e `margin: auto`
- Comentários em CSS (`/* */`)
- Estrutura semântica com `main`, `section` e `footer`

## 👀 Como visualizar

Abra os arquivos `.html` no navegador e mantenha o `estilo.css` na mesma pasta do primeiro exemplo.
