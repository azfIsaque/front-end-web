# 📱 Aula 11 — Bootstrap

[⬅️ Voltar ao README principal](../README.md)

## 📌 Resumo da atividade

Introdução ao **Bootstrap 5**, framework que oferece classes CSS prontas para montar interfaces responsivas sem escrever CSS do zero. O exercício organiza dois **cards** (HTML e CSS) lado a lado em telas grandes e um sobre o outro em telas pequenas.

## 📂 Arquivos da pasta

| Arquivo | O que faz |
|---|---|
| `exemplo-de-aula01-cards.html` | Página "Aprendendo Front-End" com dois cards explicando HTML e CSS, cada um com um botão de link |

## 🧠 Habilidades abordadas

- Importação do Bootstrap 5.3.8 por **CDN**, sem instalar nada
- Sistema de grid: `container`, `row` e colunas `col-12 col-md-6`
- Responsividade: uma coluna no celular e duas colunas a partir de telas médias (tablet e computador)
- Componente **card**: `card`, `card-body`, `card-title` e `card-text`
- Cards com a mesma altura: `h-100`
- Botões com `btn` e variações de cor (`btn-danger`, `btn-info`)
- Classes **utilitárias** de cor, texto e espaçamento: `bg-secondary`, `text-center`, `text-danger`, `mb-4`, `py-4`, `g-4`
- Combinação de HTML semântico (`main`, `article`) com classes do framework

## 👀 Como visualizar

Abra o arquivo `.html` no navegador com conexão à internet, pois o CSS do Bootstrap é carregado pela CDN. Diminua a largura da janela para ver os cards se reorganizarem.
