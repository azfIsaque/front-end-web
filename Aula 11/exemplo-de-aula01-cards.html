Aprendendo Front-End

HTML

HTML é a linguagem que estrutura o conteúdo de toda página da web. Ele define o que é título, o que é parágrafo, onde entra uma imagem e para onde leva cada link — e é a primeira coisa que o navegador lê ao abrir um site. A sigla vem de HyperText Markup Language, ou Linguagem de Marcação de Hipertexto. E a palavra “marcação” é a chave: o HTML não executa nada, ele descreve.

CSS

O CSS (Cascading Style Sheets ou Folhas de Estilo em Cascata) é uma linguagem de estilo usada para definir a aparência visual de páginas da web. O CSS é uma linguagem de estilo usada no design de páginas da web. Desenvolvida na década de 90, a linguagem foi criada para solucionar um problema criado pela expansão da internet: as páginas ficaram mais complexas, e os recursos do HTML já não eram suficientes para atender às necessidades dos desenvolvedores.
