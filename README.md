# 🌐 Desenvolvimento Front-End para Web

Repositório com os estudos, exercícios e projetos da disciplina **Desenvolvimento Front-End para Web**, ministrada pelo **Prof. Vinicius Alves Rodrigues** na **Universidade Cruzeiro do Sul**, no 2º semestre de 2026.

A disciplina apresenta as três linguagens que formam a base de qualquer site, **HTML**, **CSS** e **JavaScript**, e termina com o uso do framework **Bootstrap** para criar páginas responsivas.

---

## 🎯 Sobre a disciplina

O front-end é a parte da aplicação que roda no navegador do usuário. Cada tecnologia estudada tem um papel:

| Tecnologia | Papel | Analogia |
|---|---|---|
| 🏗️ **HTML** | Estrutura e conteúdo da página | A estrutura da casa: paredes, portas e janelas |
| 🎨 **CSS** | Aparência visual e layout | O designer de interiores: cores, móveis e iluminação |
| ⚙️ **JavaScript** | Comportamento e interatividade | O que responde às ações de quem usa a página |
| 📱 **Bootstrap** | Componentes prontos e responsividade | Um kit de peças pré-fabricadas para montar a interface mais rápido |

**Principais tópicos estudados:**

- Estrutura de um documento HTML5, tags, atributos, listas, tabelas, imagens e links
- HTML semântico (`article`, `header`, `section`, `footer`) e blocos genéricos (`div`)
- Formulários, validação nativa (`required`), vídeo e áudio
- CSS: formas de inserir estilos, seletores de tipo, classe e id, box model e sombras
- Layouts com **CSS Grid** e menus com **Flexbox**
- JavaScript: variáveis, `alert`/`prompt`, eventos, `if`/`else`, `switch` e laço `for`
- Manipulação do DOM (`getElementById`, `querySelector`, `innerHTML`)
- Bootstrap 5: grid de 12 colunas, cards, botões e classes utilitárias

## 🧭 Trilha de aprendizagem

1. **Estrutura:** HTML5, tags, atributos, listas, tabelas, imagens e semântica.
2. **Interação do usuário:** formulários, áudio e vídeo.
3. **Aparência:** CSS, seletores, box model e layouts com Grid e Flexbox.
4. **Comportamento:** JavaScript, DOM, eventos, decisões e repetições.
5. **Produtividade:** Bootstrap para criar interfaces responsivas com classes prontas.

Os três pilares trabalham em camadas separadas: **HTML** (estrutura), **CSS** (apresentação) e **JavaScript** (comportamento), cada um em seu próprio arquivo sempre que possível.

## ⚙️ Como visualizar os projetos

Não é necessário compilar nada: basta um editor de código e um navegador.

```bash
git clone https://github.com/azfIsaque/front-end-web.git
cd front-end-web
```

1. Abra a pasta no **Visual Studio Code**.
2. Abra o arquivo `.html` desejado no navegador (clique duas vezes no arquivo) ou use a extensão **Live Server** do VS Code.
3. Use as **Ferramentas do Desenvolvedor** (`F12`) para inspecionar o HTML, o CSS e o console do JavaScript.

> 💡 Alguns exemplos carregam imagens, vídeos ou o Bootstrap pela internet (CDN), então é necessário estar conectado.
