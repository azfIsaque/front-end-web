# 🚀 Projeto 2 — Interface Express: CSS com IA

Projeto desenvolvido para a disciplina de **Desenvolvimento Front-End para Web**, utilizando **HTML5**, **CSS3** e apoio de **Inteligência Artificial** para criação e refinamento da interface.

O projeto consiste em uma landing page para divulgação da **Astra GameJam**, um evento fictício voltado ao desenvolvimento de jogos digitais com temática espacial.

---

## 📌 Sobre o Projeto

A proposta foi desenvolver uma página promocional para um evento de Game Jam, aplicando conceitos de:

- Estrutura semântica em HTML5;
- Estilização com CSS externo;
- Navegação por links internos;
- Layout responsivo;
- Cards informativos;
- Formulários;
- Aplicação de novas propriedades CSS;
- Utilização de IA como ferramenta de apoio ao desenvolvimento.

### 🎮 Astra GameJam

A **Astra GameJam** é um evento onde equipes de até **3 desenvolvedores** recebem um tema e possuem um período limitado para criar um jogo.

**Informações do evento:**

- 📅 Início do desenvolvimento: 07/10
- 📅 Apresentação dos projetos: 10/10
- 👥 Até 3 participantes por equipe
- 🌌 Tema: Espaço
- 🏆 Premiação: R$ 1.000,00

## 🧪 Propriedades Novas Testadas

Durante o desenvolvimento foram utilizadas propriedades CSS que ainda não faziam parte da minha prática comum:

### `linear-gradient()`

Utilizada para criar fundos com degradê e reforçar a identidade visual do projeto.

```css
background: linear-gradient(...);
```

### `box-shadow`

Aplicada em containers e cards para adicionar profundidade visual.

```css
box-shadow: 0 4px 10px rgba(...);
```

### `object-fit`

Utilizada para controlar o ajuste das imagens sem distorção.

```css
object-fit: cover;
```

### `accent-color`

Aplicada para personalizar elementos de formulário.

```css
accent-color: #xxxxxx;
```

### `outline`

Utilizada em estados de foco para melhorar a acessibilidade.

```css
outline: 2px solid #xxxxxx;
```
